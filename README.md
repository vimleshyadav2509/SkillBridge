# ResumeIQ 🚀

AI Resume Analyzer and Skill Matcher.

## 📌 Overview
ResumeIQ is an AI-powered tool designed to analyze resumes, extract key skills, and calculate an ATS (Applicant Tracking System) score to match candidates with job descriptions efficiently.

## ✨ Features
* **Resume Parsing (`resume_parser.py`):** Automatically extracts structured data and text from uploaded resumes.
* **Skill Extraction (`skills.py`):** Identifies core technical and soft skills.
* **ATS Scoring (`ats_score.py`):** Calculates how well a resume fits a given job description based on industry standards.
* **Job Matching (`job_matcher.py`):** Evaluates and compares candidate profiles with job requirements.
* **Interactive UI (`frontend/`):** A user-friendly web interface for uploading resumes and viewing analysis results.

## 🛠️ Tech Stack
* **Backend:** Python
* **Frontend:** JavaScript, CSS, HTML
